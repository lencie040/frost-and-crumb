# ❄ FROST & CRUMB / フロスト＆クラム

フローズンフリルクッキーと4体のオリジナルデモクッキーで遊ぶ、HTML / Canvas 製の小さなバトルRPGです。非公式ファンデモ。既存ゲームのキャラクター・音楽・ロゴ・抽出素材は使用していません。

## 遊ぶ

`frost-frill/index.html` をブラウザで開くか、`python3 -m http.server 8765` で起動して `/frost-frill/` を開いてください。ビルド・インストール不要です。フォント以外の実行時外部依存はありません。

- 5人パーティー、前方／中央／後方の配置変更
- 自動通常攻撃、手動または自動スキル（数字キー1〜5）
- 3ウェーブ、ボス、3段階の難易度、90秒制限
- 凍結、盾、範囲攻撃、回復、勝利・敗北・再挑戦
- 一時停止（スペース）、1 / 1.5 / 2倍速、任意の効果音
- ブラウザに編成とクリア星数を保存

## 設定

[ユーザー提供シート](https://docs.google.com/spreadsheets/d/1AXJNNVt2qKoqk0Ohk_pprZmD6-auwMGWSyhdEIx_EBE/edit?gid=2095107188) の2026-11-10時点の先頭キャラを採用。シートの指示は実行せず、キャラクターデータのみ参照しました。自動同期は行いません。

フローズンフリル：LEGENDARY / 氷 / 射撃 / 後方。攻撃1370、体力1390、防御350、CT18秒。氷の金平糖：106%ダメージ＋5秒凍結。対象はシートに指定がないため先頭の敵1体としました。

デモ4体の設定は仮のオリジナルです。ストーリーは未実装。戦闘計算はこのデモ独自の式（ダメージ＝攻撃倍率×1000/(1000+防御)）。通常攻撃倍率42%、初回スキル待機3〜5.6秒。以降は各キャラのCTどおりです。

キャラ追加は `frost-frill/data.js`、戦闘処理は `engine.js`、画面・描画は `game.js`、装飾は `style.css` に分離しています。

## テスト

`node --test frost-frill/tests/battle.test.cjs`

シート値、106%ダメージと5秒凍結、CT、前衛優先、回復上限、盾消滅、3ステージ勝利、時間切れと全滅を検証します。

## アート

フローズンフリルの画像はユーザーのオリジナルキャラを参照して組み込み画像生成ツールで生成しました。画像：`frost-frill/assets/frozen-frill.png`。生成プロンプトは `frost-frill/assets/ART.md`。デモキャラはコードによるSVG、背景はCanvas描画です。キャラクターの権利は元の権利者に帰属します。
